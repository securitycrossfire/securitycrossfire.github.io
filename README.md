# Yashon Ochieng — Cybersecurity Portfolio

Personal cybersecurity portfolio for **Yashon Ochieng**, focused on blue-team security, threat hunting, detection engineering, incident response, threat intelligence, cloud security and security automation.

## Deployment

This repository is designed for GitHub Pages and uses a static HTML/CSS/JavaScript site.

## Template

Design based on the free open-source **Codnoz Portfolio** template by [@ethicalcodnoz](https://github.com/devixsolutions12/codnoz-portfolio), customized for this portfolio.

## Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- Lenis
- Tailwind CSS via CDN
